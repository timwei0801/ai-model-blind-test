# AI 模型盲測:同一份東京行程做成網頁

同一份 Excel 行程表、同一句指令，交給 4 個不同的 AI 模型做成網頁。哪個是哪個，會在 Threads [@timwei.ai](https://www.threads.com/@timwei.ai) 揭曉。

- 網頁入口:index.html
- 這是我自己好奇做的測試，沒有業配，也不是正式的跑分，每個模型各跑一次。條件固定:同一份 Excel、同一句指令、同一個版本、能調的設定都調成一樣，每個都從空的資料夾開始。
- 網頁是 AI 產生的，內容沒有修改;只把有拍到手的照片模糊處理，飯店名稱換成代稱。
- 照片是規劃行程時從網路上存的，只當示意。
