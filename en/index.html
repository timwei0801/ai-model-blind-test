AI model blind test

Same Tokyo trip,
5 AIs, 5 web pages

I gave the same Excel itinerary (9 days, 5 adults, 48 photos of places) to 5 different AI models, with the exact same one-line prompt. Four of them (A–D) are in the vote. The fifth (E) is below too, so you can compare.

The prompt they got (translated from Chinese)Turn this Tokyo itinerary into a polished, good-looking HTML page. Include the photos from the spreadsheet, and make it work on a phone.

Not telling you which is which yet. Open them on your phone: which one did the best job?

About this testJust my own curiosity: not sponsored, not a formal benchmark, one run per model. Fixed conditions: same Excel file, same prompt, same Claude Code version, effort set to high (Haiku doesn't support effort, so it ran on its default), and every run started from an empty folder.
  • Photos with hands in them are blurred, and hotel names are replaced with placeholders like "Tokyo Hotel".
  • The photos were saved from the web while I planned the trip, for illustration only.
  • Prices and times on the pages are planning estimates, not travel advice.
